# ADR-003: Real-time совместная работа

## Статус

Принято.

## Контекст

WTF должен поддерживать совместное редактирование и live-обновления. Self-hosted сценарий требует простого горизонтального масштабирования и устойчивости к временной потере соединения.

## Решение

Используем Yjs для CRDT-документов и WebSocket для передачи обновлений. Между инстансами API/realtime события распространяются через Redis pub/sub. Для тестов и одиночного процесса доступен in-memory event bus с тем же интерфейсом.

## Последствия

Слой совместной работы можно масштабировать отдельно. Конфликты rich text решаются на уровне CRDT, а CRUD-события задач остаются доменными событиями.
