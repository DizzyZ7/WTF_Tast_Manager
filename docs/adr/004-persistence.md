# ADR-004: PostgreSQL, Drizzle и репозитории

## Статус

Принято.

## Контекст

Данные проекта имеют реляционную природу: workspace, members, projects, issues, comments, relations и activity log. Нужны транзакции, индексы, миграции и переносимость self-hosted установки.

## Решение

PostgreSQL выбран основным хранилищем. Drizzle ORM используется для типизированных схем и миграций. Весь доступ к данным проходит через реализации репозиториев в `@wtf/db`.

## Последствия

Домен не зависит от ORM. Схема явно версионируется SQL-миграциями, а локальный Docker Compose поднимает готовую базу с начальными таблицами.
