# @wtf/core

`@wtf/core` содержит DDD-модель WTF: агрегаты, value objects, доменные события, ошибки и интерфейсы репозиториев.

## Архитектурное решение

Пакет не имеет runtime-зависимостей. Это осознанная граница: домен не импортирует Fastify, Drizzle, Zod, Redis или React. Все внешние слои работают через снимки агрегатов, доменные события и интерфейсы репозиториев.

## Команды

```bash
pnpm --filter @wtf/core build
pnpm --filter @wtf/core test:coverage
```

## Основные агрегаты

- `Workspace` - членство, роли и инварианты владельцев.
- `Project` - проектная идентичность, ключи и спринты.
- `Issue` - жизненный цикл задачи, комментарии, подзадачи, связи и activity log.
