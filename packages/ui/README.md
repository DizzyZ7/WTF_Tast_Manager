# @wtf/ui

`@wtf/ui` - переиспользуемые React-компоненты WTF.

## Архитектурное решение

Компоненты не делают сетевых запросов и не знают о доменных репозиториях. Они принимают данные через props, поэтому могут использоваться в Next.js, Storybook или тестовых harness без инфраструктуры.

## Команды

```bash
pnpm --filter @wtf/ui build
pnpm --filter @wtf/ui test
```
